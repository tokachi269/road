# 履歴

この文書は、現在の構成へ至った理由を短く残します。
作業手順や現行契約を調べる用途には使いません。

## 当初の目的

CSUR専用ではない、CS1向け道路生成器として開始しました。
Groundだけでなく、Elevated、Bridge、Tunnel Entrance、Tunnelを対象にしています。

RoadImporterとCSURは参考実装として調査しました。
生成器の実行時依存にはしていません。

## 主な修正の流れ

初期版は、設定と派生値がUI、JSON、meshへ重複していました。
その後、Blender非依存の判断を`domain.py`へ移しました。

UVはPSDの見た目を基準にしていたため、座標ずれが発生しました。
現在は`textures/dimensions.json`と独立したtestを基準にしています。

Runtime previewでは、IMTの編集を定期的に上書きする試作を行いました。
操作競合と負荷を避けるため、現在は作成イベントと明示的な復元操作を使います。
